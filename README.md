# Sudoku Solver

A Python-based Sudoku solver using Constraint Satisfaction Problems (CSP).

## Features
- Backtracking search
- Forward checking
- MRV and degree heuristics
- Least Constraining Value (LCV)
- Puzzle generation and benchmarking
- Automated tests
- Optional Anthropic API and Google OR-Tools integration

## Usage

Run the solver:
python sudoku_csp_solver.py

Run tests:
python sudoku_csp_solver.py --test

Run benchmarks:
python sudoku_csp_solver.py --bench

## Technologies
Python, CSP, Backtracking, Search Heuristics, AI.
